# AIモデル早見表 設計

## 目的
OpenAI / Anthropic / Gemini / Grok / Muse の現行モデル名と版番号を、開けばいつでも最新の状態で確認できる公開ページ。モデル名を覚えられない本人のための早見表。

## やること・やらないこと
- やる: 5社の現行モデル一覧、会社順（既定）と賢い順の切り替え、毎日の自動更新。
- やらない: ローカルLLM（Llama、Gemma、gpt-oss）、画像・音声・動画専用モデル、料金比較。
- 失敗の定義: 取得元が落ちたときにページが空になること。古いデータのまま残す。

## 検討した作り方
1. **Actions が毎日 `data.json` を作り、ページはそれを読む（採用）**。取得元が落ちても前回分が残る。
2. ブラウザから毎回取得元を直接読む。取得元の障害や仕様変更でページが壊れるので不採用。
3. 各社の公式 API を使う。鍵が5社分必要なので不採用。

## データ
- モデル一覧: `https://openrouter.ai/api/v1/models`（鍵不要）。
- 点数: Arena 公式データ `lmarena-ai/leaderboard-dataset`（CC BY 4.0）の `text` / `latest`、`category = overall`。datasets-server の `/rows` を先頭から読み、`overall` が終わったら止める。
- 対象: ID が `openai/gpt-*|o<数字>*|chatgpt-*`（`gpt-oss` 除く）、`anthropic/claude-*`、`google/gemini-*`、`x-ai/grok-*`、`meta/muse-*`。`:` 付きの派生版、出力がテキスト以外を含むもの、提供終了日を過ぎたものは除く。
- 名寄せ: 両方の名前を「小文字化、括弧内を削除、会社名の接頭辞を削除、ハイフンを空白に、preview/beta を削除」して一致させる。同じモデルに複数の点があれば最高点。一致しなければ未評価。
- 現行の判定: 名前から版番号を除いたものを系列とし、系列ごとに公開日が最新のものを現行とする。ただし、その会社の最新モデルの公開日から120日より前のものは旧モデル扱い（主要な最新世代だけを見せるため）。さらに、その会社で最も大きい世代番号（例: Gemini 4）のモデルだけを現行とする。版番号の無いモデル（例: Muse Ember）は世代の条件を問わない。`contributor` 付きの派生版は載せない。
- Arena の取得に失敗したら前回の点数を引き継ぐ。OpenRouter の取得に失敗、または5社のどれかが0件なら `data.json` を書き換えずに異常終了する。

## 画面
- 会社順（既定）: 5社を横に並べた列で表示。中の並びは「公開30日以内の未評価（NEW）→ 点数の高い順 → 残りの未評価を新しい順」。
- 賢い順: 5社を1本にまとめて点数の高い順。未評価は末尾。
- 旧モデルは「旧モデルも表示」で開く。モデル名を押すと API 用 ID をコピー。
- 最終更新日時と Arena の集計日を表示。

## 構成
- `index.html`: ページ本体（外部ライブラリなし）。
- `data.json`: 生成物。
- `scripts/update.py`: 取得と整形（Python 標準ライブラリのみ）。`scripts/test_update.py`: 単体テスト。
- `.github/workflows/update.yml`: 毎日 06:17 JST と手動実行。差分があればコミット。
- 公開: GitHub Pages（main ブランチ直下）。
